# Aura — personal Oura data viewer

Aura is a private, single-user dashboard for viewing the owner's Oura health metrics on devices they control. It uses the official Oura Cloud API V2 after the owner authorizes access. It is not affiliated with Oura Health Oy and does not sell or share health data.

- [Privacy policy](privacy.md)
- [Terms of use](terms.md)

The app runs on the owner's Mac. Its dashboard is accessed from the owner's PC through a local, encrypted SSH connection. No Oura health data is stored in this public repository.
